# FW-EC-PROBE C0 工程评审资料

**这是按新要求重建的工程评审版，尚不是可直接发板厂生产的定版资料。**

本版替代旧 B0 大板、独立隔离板和 LT5400 转接片方案。只保留四电极电导率、四线 Pt1000 温度、温补与隔离 RS-485；提供两极兼容焊桥和最小 SWD 焊盘，不恢复显示、编码器、蜂鸣器、LED 或旧评估接口。

用户已明确选择保留原 Rev A 模拟链，取消原连续工作 ≤30 mA 限制；外壳依据为随包 HR8033 原手册。没有把附件外径当内径，也没有用不明系数冒充 ISO nLF。

## 已完成到什么程度

- 原 ADI BOM 197 位号逐项覆盖：保留158、删除39，所有删件不进入新板采购表。
- 完整逐脚转录合并到原生 KiCad 电气工程；总工程210位号，前板165、后板45。新供电/隔离器件列独立变更与来源。
- 前板已生成16.5×105mm、四层1.0mm的真实封装 PCB 布局草案；元件横向包络检查通过，含接头的轴向包络约108.905mm。选定草案有1722条铜线段、186个过孔，仍有70项缺线及67项警告；原理图一致性差异为0。DRC没有通过，不能生产，实际计数见随包报告。
- 固件含 HR8033 兼容整数寄存器、扩展浮点寄存器、9600 8N1 默认、120ms可配置稳定等待、32档校正表与有校验/限频的 Flash 参数存储。主机软件验证通过；HEX 是 Rev A 引脚台架候选，没有上新板验证。
- 采购 Excel/CSV 覆盖电子料与探头、标准液、温浴、参考仪器、外壳和焊接工具耗材。未核实型号、商城 SKU、库存、价格和证书能力的行明确 HOLD/UNVERIFIED。
- 前板裸板 STEP、假设高度包络 STEP、截面及空间分析已输出；模型不等于现有外壳适配证明。

## 仍未完成，不能作为投产依据

1. 后板 T201 变压器真实机械图/物理脚号、L202 准确焊盘、U203 当前 RD-8-4 裸露焊盘图未核实；后板PCB、完整两板装配模型和生产CAM未完成。
2. 前板的全部布线及整套 ERC/DRC 零错误尚未完成。原生 ERC 保留 ADuCM360 7/18 两稳压输出相连的真实规则冲突；原图及数据手册要求两脚相连，未通过伪造引脚类型或关闭检查来得到0。
3. 现壳体的内径、电子仓净长和端头占用没有厂家制造图；约109mm前板后只剩约19mm外部跨度，仍须装后板和尾接头，现布局不能声称已适配HR8033。
4. 正式 ISO 7888 天然水 nLF 因子仍缺，κ25默认无效并置标志；对应HR整数寄存器返回FFFFFFFF。该成品温补功能未完成。
5. R13/R47与8只衰减电阻的合格完整订货码、完整探头型号仍待定标；不能按旧原料号购买后宣称满足升级精度。
6. 电导率±0.5%、温度±0.05°C、整机≥1kV隔离、温升/防水/EMC、极化和120ms建立时间均没有实物验收结果。

## 使用顺序

先读交付状态、未完成清单和BOM使用说明，再打开 KiCad 9 工程核图。厂家现阶段可做工程可制造性评审和器件询价；**不要把本包、旧B0 Gerber或原ADI Gerber作为本C0成品下单文件。** 本版没有生成假造的可生产Gerber、钻孔或DRC零错误证明。

调试读取精确电导率使用扩展float32。HR0006的整数µS/cm在低端无法表达±0.5%精度；通信格式兼容不等于重现HR8033的水压/水位功能。主机端校准和配置步骤见 `firmware/README.md`。

## 重建与验证

固件：GNU Arm Embedded GCC，`cd firmware && make test && make`；可通过`CROSS_COMPILE`指定工具链，详见其README。测试通过只证明软件范围内的结果。

CAD生成依赖KiCad9，系统Python需有pcbnew绑定；机械脚本使用FreeCAD/Part，采购和评审文档使用openpyxl/ReportLab/PyMuPDF。`tools/generate_native.py`生成总电气工程，`generate_board_schematics.py`分出前/后板电气工程；真实导出网表可用`verify_cad_electrical.py`逐脚比较。电气转录脚本从随包`references/`读取官方原理图和逐位号BOM，原厂模拟器件数据表另存`references/analog_datasheets/`。

不得把缺失的原ADI可编辑CAD伪装成已取得；随包新的KiCad文件为从官方PDF独立重建的工程草案。ADI原始授权条款随固件和原始资料保留。
